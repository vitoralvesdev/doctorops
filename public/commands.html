Lista de Comandos

A descoberta é o modo oficial. O terminal da página Descoberta executa os comandos ADB listados abaixo.

Dispositivo

Sintaxe Descrição Status
list <ip-ou-nome>
list 192.168.1.50 		Identifica o aparelho e, se o ADB estiver acessível, exibe um painel completo com:
  • Tipo detectado (Android TV, TV Box, Android, Apple) e modelo/fabricante
  • Identificação: fabricante, marca, modelo, CPU, Android, SDK, Build ID
  • Memória RAM: total, em uso (com barra de progresso), disponível
  • Armazenamento /data: total, usado, livre
  • Uptime do sistema
  • Bateria: nível %, status e temperatura
  • Todas as conexões detectadas neste aparelho
Se o ADB não estiver acessível, mostra as conexões encontradas e instruções de pareamento. 		✓ Ativo
probe <ip> [full]
probe 192.168.1.26 		Diagnóstico profundo de um IP: portas TCP, banners HTTP/RTSP, SSDP/mDNS/NetBIOS, TTL, MAC e fabricante do módulo Wi-Fi (OUI local). Com full, varre 1–65535. Grava fabricante e portas no cache de hosts. Útil para boxes que aparecem como desconhecidas. ✓ Ativo
usb
usb 		Mostra o que o adb lista e o que o Windows enumerou no USB (VID/PID, classe e nome), com a diferença em relação à consulta anterior. Rode sem o cabo, conecte o cabo e rode de novo: se nada novo aparecer, o cabo é só de carga ou a porta não faz conexão de dados. ✓ Ativo
tcpip <serial-usb> [porta]
tcpip 0123456789ABCDEF 		Converte um aparelho conectado por USB em ADB de rede (adb tcpip). Descobre o IP pela shell, tenta persistir persist.adb.tcp.port quando há root e conecta em seguida. Necessário apenas uma vez; depois use connect <ip>. ✓ Ativo
clear
clear 		Limpa apenas o que está na tela do terminal. O histórico de comandos e os registros salvos continuam intactos. ✓ Ativo
help
help 		Lista os comandos aceitos pelo terminal. ✓ Ativo

Pareamento e ADB

Sintaxe Descrição Status
pair <ip:porta> <código>
pair 192.168.1.50:37123 123456 		Pareia a depuração sem fio (Android 11+) usando a porta e o código exibidos em Opções do desenvolvedor → Depuração sem fio → Parear dispositivo na TV. A porta de pareamento é diferente da porta de conexão e muda a cada pareamento. ✓ Ativo
connect <ip-ou-nome[:porta]>
connect 192.168.1.50:5555 		Conecta via ADB. Porta padrão: 5555 (Android 10 ou menor). Após o pareamento, use a porta de conexão exibida na tela de Depuração sem fio. ✓ Ativo
disconnect <ip-ou-nome[:porta]>
disconnect 192.168.1.50:5555 		Desconecta uma sessão ADB. ✓ Ativo

Controle

Sintaxe Descrição Status
abort
abort 		Cancela a operação em andamento no servidor (varredura de rede, conexão ADB, coleta de dados). Útil quando o terminal travar ou a operação demorar mais do que o esperado. ✓ Ativo

Apps e arquivos (ADB)

Sintaxe Descrição Status
apps <ip|serial>
apps 192.168.1.12 		Lista apps de usuário e de sistema instalados na box. ✓ Ativo
install <ip|serial> <apk>
install 192.168.1.12 "C:\apps\app.apk" 		Instala ou atualiza um APK do PC. No painel de Descoberta também dá para escolher o arquivo e enviar direto (botão Instalar APK). ✓ Ativo
uninstall <ip|serial> <pacote> confirmar
uninstall 192.168.1.12 com.exemplo.app confirmar 		Remove um app pelo pacote. Sem confirmar o comando apenas pede confirmação. Apps de sistema podem exigir pm uninstall --user 0, que o servidor tenta em seguida. ✓ Ativo
screen <ip|serial>
screen 192.168.1.12 		Captura a tela e mostra a prévia no painel de Descoberta. ✓ Ativo
push <ip|serial> <arquivo> [destino]
push 192.168.1.12 "C:\video.mp4" /sdcard/Download/ 		Copia um arquivo do PC para a box (padrão /sdcard/Download). ✓ Ativo
reboot <ip|serial> confirmar
reboot 192.168.1.12 confirmar 		Reinicia a box. A sessão ADB cai e volta em alguns segundos. ✓ Ativo

Mapa de capacidades

Carregando capacidades…
Como os comandos funcionam: os comandos (list, apps, install, uninstall, screen, push, reboot) rodam no servidor Node.js local via adb e só funcionam se a box expuser a depuração e autorizar a conexão. O terminal não é um shell livre — apenas os comandos listados aqui são aceitos. Em aparelhos ligados por cabo USB, use o serial exibido por adb devices como alvo (ex.: apps RQ8R205WKDW). Para o ADB funcionar em Android 11+ é necessário pair com o código exibido na TV; em Android 10 ou menor, basta connect ip:5555 e aceitar o aviso na tela. O Agent com IA é um roadmap: interação em linguagem natural ainda não está disponível.
